## Project Information

The project aimed to run an energy code compliance analysis for a self-storage facility using IESVE. The study evaluated in detail the building envelope, HVAC, and lighting systems against IECC 2021 standards. Generated simulation-based compliance reports, technical documentation for city approval, compared baseline and proposed performance, and recommended design adjustments to ensure regulatory approval and optimized energy efficiency. Since the main objective was to reduce the construction cost, after simulating and troubleshooting the unmet hours, there were major recommendations in reducing the reducing the insulation while still complying with the code. This resulted with major cost reductions.
